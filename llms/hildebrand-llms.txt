# Hildebrand Technology Limited (Glow / Glowmarkt)

> Hildebrand is a London-based energy data company and, since 2019, the United Kingdom's first
> independent DCC Other User with a direct connection to the national smart-metering network
> (SEC Party Identifier PLK001). It makes Glow hardware, stores GB smart-meter reads at scale, and
> republishes them through the Glowmarkt Platform APIs, the consumer Bright app, and the commercial
> Glow Data Service. Britain mandated the metering INFRASTRUCTURE, not a consumer data right, so
> there is no Consumer Data Right or Green Button obligation here — the API is a commercial product,
> not a compliance artifact.

## How access works

- Your own household data: FREE and self-serve. Install the Bright app, create an account, pass
  meter-point verification, then call the production API with the published individual
  applicationId `b0f1b774-a586-4f72-9edd-27ead8aa7a8d`.
- Other people's data: PAID and contracted. Glow Data Service starts at GBP 595/month per MPxN
  (Core), GBP 2,600/month + per MPxN (Enterprise), with consumer verification and consent captured
  per meter point.
- Every call needs TWO headers: `token` (a JWT from POST /api/v0-1/auth, 7-day lifetime) and
  `applicationId`. Anonymous calls return HTTP 400, not 401.

## APIs

- [Glowmarkt User System API](https://api.glowmarkt.com/api-docs/v0-1/usersys/usertypes/): users,
  accounts, JWT auth, an OAuth 2.0 authorization-code grant, and per-MPxN meter point consent and
  verification. Base URL https://api.glowmarkt.com/api/v0-1
- [Glowmarkt Resource System API](https://api.glowmarkt.com/api-docs/v0-1/resourcesys/): time-series
  energy data — readings with ISO 8601 aggregation periods, current readings, meter reads, tariffs
  and tariff history, DCC catchup, daily consumption log, Glow Binary raw data.
- [Glowmarkt Virtual Entity System API](https://api.glowmarkt.com/api-docs/v0-1/vesys/): homes and
  sites, their resources, types and metadata attributes.
- [Glowmarkt Device Management System API](https://api.glowmarkt.com/api-docs/v0-1/dmssys/): Glow
  gateways, sensors and actuators, the DCC inventory of a meter point by MPxN or EUI, gateway status.
- [Glowmarkt Notification System API](https://api.glowmarkt.com/api-docs/v0-1/notificationsys/):
  alert types, per-channel/per-culture templates, alerts and delivery logs. Base path /api/v0-1/ns

## Key data semantics

Resource `classifier` values: `electricity.consumption` (kWh), `electricity.consumption.cost`
(pence), `electricity.export` (kWh), `electricity.import.reactive` (kVARh),
`electricity.export.reactive` (kVARh), `gas.consumption` (kWh), `gas.consumption.cost` (pence).

Aggregation `period` values and their maximum query window: PT1M (electricity only), PT30M (10
days), PT1H (31 days), P1D (31 days), P1W (6 weeks), P1M (366 days), P1Y (366 days). `offset` is
minutes between your timezone and UTC, sign-inverted (BST = -60).
